Option A — Native menu (NSMenu)

SwiftUI MenuBarExtra(.menu) / NSMenu : menu système pur. Éléments avec sous‑titre (macOS 14+), sous‑menu par WI pour changer l'état, sous‑menu Mute.

Essayer : survol des WI (sous‑menu), « Mute Notifications », états ci‑dessous. Le menu se ferme après chaque action (comportement natif).

Principe & limites

  • 100 % natif, zéro layout custom, navigation clavier/VoiceOver gratuites. Le plus rapide à développer.
  • Un élément avec sous‑menu n'est pas cliquable sur macOS → WI : « Open in Browser » déplacé dans son sous‑menu (1 niveau de plus).
  • Pas de contenu riche : votes en texte, pas de pill, pas de bandeau coloré, pas de spinner. Erreur de transition ADO → alerte (NSAlert) ou notification, car le menu est fermé.
  • Menu non scrollable proprement au‑delà de l'écran → plafond 10 lignes/section + « Show N more in browser… ».
  • Pas de sélecteur de date dans un menu → « Until Date… » ouvre une petite fenêtre.
