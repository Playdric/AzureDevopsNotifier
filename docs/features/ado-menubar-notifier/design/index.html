ADO Menu Bar Notifier — maquettes

Panneau : 3 options. Écrans communs (icône, setup, Settings, notifications) : identiques pour toutes.

Option A — Native menu (NSMenu)

Menu système pur. Le plus natif et le plus simple ; contenu pauvre, changement d'état en sous-menu, erreurs en alerte.

 Option B — Popover, sections empilées ★ recommandée

Panneau verre, 3 sections repliables, pill d'état, bandeaux, erreur inline. Tout visible d'un coup d'œil.

 Option C — Popover à onglets

Même panneau, contrôle segmenté : une liste à la fois, compteurs par onglet.

 Écrans communs

Icône barre de menus (5 états), configuration initiale, Settings (General / Account / Projects / States), notifications.
